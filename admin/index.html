First-time Setup

  1. Start backend: cd server → npm install → npm run dev
  2. Open this page via: http://localhost:5174/admin/
  3. Request login link with your admin email
  4. Check backend console for the magic link (dev mode)
  5. Open a template and use click-to-edit directly in the preview

Quick Tips

  • Text editing: Click headings, paragraphs, links, or list items in preview and type directly.
  • Image insertion: Select an image or container, paste URL, then use Insert / Replace Image.
  • Layout modules: Add hero, feature, or cards blocks and customize their copy afterward.
  • Save shortcut: Press Ctrl+S or Cmd+S to save the active template.
