📋 First-time Setup

  1. Start backend: cd server → npm install → npm run dev
  2. Open this page via: http://localhost:5174/admin/
  3. Request login link with your admin email
  4. Check backend console for the magic link (dev mode)
  5. Edit & save catalogue items and config

💡 Quick Tips

  • Catalogue structure: Each item needs id, name, category, price, and other fields
  • Config structure: Add contact URLs, WhatsApp links, email addresses
  • Validation: Check browser console for JSON errors
  • Backup: Save your JSON changes locally before committing
