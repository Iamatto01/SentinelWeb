        Simple workflow to deliver client websites with zero hosting cost
        Recommended free workflow
        1. Client picks a template and sends the template code (SKU) via WhatsApp/Email/DM.
        2. You customize logo, text, colors, and contact details.
        3. Deploy free on Cloudflare Pages, Netlify, or GitHub Pages.
        4. Use a clean URL format like brandname-city.pages.dev or brandname.netlify.app.
        5. Generate a QR from the final URL and share it for flyers, cards, and storefront stickers.
        Good URL + QR tips
        • Keep URL short: businessname + area (example: zencafe-jb.pages.dev).
        • Avoid numbers and long words so clients can type it easily.
        • Use qr-code-generator.com or canva.com/qr-code-generator for branded QR.
        • Always test QR on iPhone + Android before sending to client.

        Edit these in catalogue/config.js (search CONTACT) so the Get this website button sends clients to you.
