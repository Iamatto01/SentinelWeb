🧠 HOW IT WORKS:

1. Backend generates unique HTML every 5 minutes using Claude Opus
2. React dashboard shows live preview of pending websites
3. You approve/reject each design one-by-one
4. Approved sites auto-commit to: Iamatto01/SentinelWeb repo
5. Files organized in: server/data/generated/

Complete Workflow:
  Timer (5min)
    ↓
  Claude generates HTML
    ↓
  Saved to pending/
    ↓
  Dashboard shows preview
    ↓
  You approve or reject
    ↓
  Approved → GitHub commit
  Rejected → Discarded

📡 API ENDPOINTS:

GET    /api/generator/pending              → List pending sites

GET    /api/generator/pending/{id}         → View HTML
POST   /api/generator/approve/{id}         → Approve & commit
POST   /api/generator/reject/{id}          → Reject design
